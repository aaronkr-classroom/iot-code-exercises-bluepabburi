# chp1 연습문제

1.Q1
  - (a) 디바이스의 센서와 액추에이터의 역할을 비교하여 설명하세요.
    
      센서와 액추에이터는 IoT 시스템이 외부 세계와 소통하는 양방향 통로입니다. 센서는 인간의 감각 기관처럼 온도, 습도, 빛, 움직임 같은 물리적인 환경 변화를 감지하여 이를 디지털 신호로 변환해 시스템에 전달하는 입력 역할을 수행합니다. 반면, 액추에이터는 시스템의 판단에 따라 물리적인 동작을 실행하는 장치입니다. 전기적 신호를 받아 모터를 돌리거나, 밸브를 열거나, 불을 밝히는 등 실제 환경에 물리적인 변화를 일으키는 출력 역할을 담당합니다. 즉, 센서가 환경을 '읽는' 것이라면 액추에이터는 환경에 '작용'하는 것입니다.

  - (b) 디바이스와 대시보드에서 동일한 프로그래밍 언어를 사용하지 않는 이유를 설명하세요.

      이 두 영역은 작동하는 목적과 하드웨어 환경이 극명하게 다르기 때문입니다. 디바이스는 대개 메모리와 처리 능력이 매우 제한된 임베디드 환경에서 작동하므로, 자원을 극도로 아끼면서 하드웨어를 직접 제어할 수 있는 C나 C++ 같은 고성능 저수준 언어가 적합합니다. 반면, 사용자가 보는 대시보드는 복잡한 데이터를 시각화하고 다양한 웹 브라우저나 모바일 환경에서 유연하게 돌아가야 합니다. 따라서 개발 생산성이 높고 UI 처리에 최적화된 JavaScript나 Python 같은 고수준 언어를 사용하는 것이 훨씬 효율적입니다. 각 층위의 목적에 맞는 '적재적소'의 도구를 선택하는 과정이라 이해할 수 있습니다.

  - (c) 브로커와 같은 정보 전달 전담 서버의 이점을 설명하세요.

      브로커를 도입하면 전체 시스템의 유연성과 신뢰성이 크게 향상됩니다. 우선, 정보를 주는 쪽(발행자)과 받는 쪽(구독자)이 서로의 IP 주소나 상태를 직접 알 필요가 없는 디커플링(Decoupling) 상태가 되어, 장치가 추가되거나 변경되어도 전체 시스템에 영향을 주지 않습니다. 또한, 수많은 디바이스의 연결 관리를 브로커가 전담하므로 개별 기기의 통신 부하를 줄여줍니다. 특히 네트워크 상태가 불안정한 IoT 환경에서 브로커는 메시지를 잠시 보관했다가 장치가 연결되었을 때 확실히 전달해 주는 중재자 역할을 수행하여 데이터 유실을 방지합니다.

2. Q2
- (c) Mosquito와 Node-RED에 대해 설명하고 실행에 적합한 컴퓨팅 환경을 제시하십시오.

  Mosquitto는 MQTT 프로토콜을 기반으로 메시지를 중계하는 가볍고 강력한 오픈 소스 브로커입니다. 낮은 전력과 적은 메모리로도 수많은 장치 간의 메시지 교환을 안정적으로 처리하는 '디지털 우체국'과 같은 역할을 수행합니다. 이와 함께 쓰이는 Node-RED는 시각적인 노드 연결 방식을 통해 데이터 흐름을 설계하는 로우코드(Low-code) 도구입니다. 복잡한 코딩 없이도 센서 데이터를 가공하거나 특정 조건에 따라 액추에이터를 제어하는 논리 회로를 쉽게 만들 수 있는 '제어 타워' 역할을 합니다.

이러한 도구들을 실행하기에 가장 적합한 컴퓨팅 환경은 라즈베리 파이와 같은 싱글 보드 컴퓨터입니다. 저전력으로 24시간 내내 가동할 수 있으면서도 Linux 기반의 안정적인 운영이 가능하기 때문입니다. 만약 더 대규모의 시스템이나 원격 관리가 필요하다면 AWS나 Azure 같은 클라우드 서버 혹은 도커(Docker) 컨테이너 환경에서 구동하는 것이 유지보수와 확장성 측면에서 가장 합리적인 선택이 됩니다.
